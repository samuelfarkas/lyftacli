# Security policy

## Supported versions

Only the latest release receives security updates.

## Report a vulnerability

Please do not open a public issue. Send the report through [GitHub's private vulnerability reporting](https://github.com/samuelfarkas/lyftacli/security/advisories/new) and include:

- the affected command and version;
- reproduction steps or a proof of concept;
- what an attacker could do;
- a suggested fix, if you have one.

You should receive an initial response within seven days. We will keep the report and fix private until we agree that they are ready to disclose.
